# Brand assets

The state-db mascot is a sea otter floating in the water — state you can let
float safely. The original artwork is raster (`statedb-logo.png`,
`statedb-mascot.png`); the SVGs are auto-traced from it by the pipeline in
[`trace/`](trace/README.md), so they carry the exact hand-drawn linework and
letterforms. Don't edit the SVG path data by hand — re-run the pipeline
instead.

## Files

| File | What it is | Use it for |
| --- | --- | --- |
| `statedb-mark.svg` | Square otter mark, light backgrounds | Favicons, avatars, app icons, docs |
| `statedb-mark-dark.svg` | Square otter mark, dark backgrounds | Dark-mode docs and sites |
| `statedb-logo.svg` | Horizontal lockup (mark + wordmark + tagline), light backgrounds | README headers, websites, slides |
| `statedb-logo-dark.svg` | Horizontal lockup, dark backgrounds | Dark-mode headers |
| `statedb-mark-512.png` | 512×512 transparent render of the mark | GitHub org avatar, Slack, places that reject SVG |
| `statedb-logo.png` | Original illustrated lockup (raster, off-white background) | Source of truth for tracing; print, social cards |
| `statedb-mascot.png` | Full-body mascot illustration | README, blog posts, swag |

The web console's copies are generated by the same pipeline: the favicon
(`modules/web/favicon.svg`) swaps colors with the browser theme via
`prefers-color-scheme`, and the mark is inlined as a React component
(`modules/web/src/components/brand/BrandMark.tsx`) so it can follow the
console theme through `currentColor`.

## Palette

| Color | Hex | Role |
| --- | --- | --- |
| Navy | `#182B4D` | Outlines, wordmark "state", text |
| Royal blue | `#2563EB` | Waves, wordmark "db", accents |
| Cream | `#F7F3E8` | Face fill |
| Pale slate | `#DBE4F2` | Outline color on dark backgrounds |
| Bright blue | `#3B82F6` | Wave/accent color on dark backgrounds |

## Embedding in Markdown

GitHub renders the right variant for the viewer's theme with a `<picture>`
block:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/brand/statedb-logo-dark.svg">
  <img src="assets/brand/statedb-logo.svg" alt="statedb — self-hosted state backend" width="460">
</picture>
```
