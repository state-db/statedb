# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct.

The full text is available at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — opening issues, submitting pull requests, commenting, or otherwise engaging in project spaces — contributors agree to abide by that document.

## Scope

This applies to all project spaces: the GitHub repository (issues, pull requests, discussions, commits), any official chat channels, and any other communication channel established for the project.

## Reporting

Please report unacceptable behavior privately to a project maintainer. You can reach a maintainer directly via their GitHub profile — visible on any commit in this repository's history.

If you cannot use that channel, open a minimal public issue saying "I would like to raise a Code of Conduct concern privately" — do **not** include details in the public issue — and a maintainer will follow up through GitHub.

Reports will be reviewed in confidence and handled in accordance with the enforcement guidelines set out in the Contributor Covenant.

## Maintainer discretion

Project maintainers may remove, edit, or reject contributions that do not align with this Code of Conduct, and may temporarily or permanently ban any contributor for behavior they deem inappropriate, threatening, or harmful — at their sole discretion and consistent with the Contributor Covenant.
