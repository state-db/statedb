# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct.

The full text is available at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project, including opening issues, submitting pull requests, and commenting, contributors agree to abide by that document.

## Scope

This applies to all project spaces: the GitHub repository (issues, pull requests, discussions, commits), any official chat channels, and any other communication channel established for the project.

## Reporting

Report unacceptable behavior privately to a project maintainer. Maintainers are reachable through the GitHub profile shown on any commit in this repository.

If you cannot use that channel, open a public issue that says only "I would like to raise a Code of Conduct concern privately", with no details. A maintainer will follow up through GitHub.

Reports are reviewed in confidence and handled under the enforcement guidelines in the Contributor Covenant.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this Code of Conduct, and may temporarily or permanently ban contributors for inappropriate, threatening, or harmful behavior, consistent with the Contributor Covenant.
